Year Progress (opens in a new tab)

Problem
A year, a month, or a day can pass without a clear sense of how much of it is already gone.

Stack

Apple Events Monitor (opens in a new tab)

Problem
New in-person and online sessions on Apple's public developer events page are easy to miss.
Contribution
I wrote a Python script that loads that public page, collects event links and dates, skips entries it has already seen, and skips dates listed in config/blackout.json. It writes data/events.json and calendar/apple-developer-events.ics, and prints a summary when it finds something new. GitHub Actions runs it every 6 hours and can be started by hand. The repository includes tests. The README says it uses the public page and does not need a paid API.
Stack
Python and GitHub Actions.
Result
An updated event list, and an ICS file that can be imported into Apple Calendar or Google Calendar.
